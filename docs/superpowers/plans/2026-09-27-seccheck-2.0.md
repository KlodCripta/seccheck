**Goal:** Build the approved bilingual Petrolio terminal security assistant with evidence-based results and Atomic Arch checks.

**Architecture:** Keep one distributable Bash script with separate named sections for state, language, adapters, AUR inspection and UI. Findings and coverage are independent; rendering never changes assessment. Store each run in a private directory.

**Tech Stack:** Bash 4.4+, GNU coreutils/find/grep, pacman, rkhunter, Lynis, pacutils; Python standard library only for development tests.

**Spec:** docs/superpowers/specs/2026-09-27-seccheck-2.0-design.md

## Global Constraints

- Standalone `seccheck.sh`; MIT; only Arch and derivatives for scans.
- Startup language 1 English / 2 Italiano; Petrolio UI, narrow/ASCII/no-color modes.
- No probability scores, false completion, unrelated cross-confirmation or automatic remediation.
- Preserve raw evidence safely; no execution of scanned files or unverified remote feeds.
- Native Arch execution is an explicitly outstanding release gate.

## Review Focus

- Unknown/changed upstream output, stderr-only errors and partial scans retain uncertainty.
- Sudo identity, paths containing whitespace/metacharacters and malicious terminal escapes.
- Missing/truncated caches or modules do not erase strong evidence or become full coverage.
- Package integrity corroborates file properties only, not trust in package provenance.
- Root-running test harness and report cleanup never touch existing production logs.
